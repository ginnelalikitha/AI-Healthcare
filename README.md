# 🥗 AI Healthcare Nutrition Coach

A Multi-Agent AI Healthcare Assistant built using Python and Streamlit.

---

## Features

- Nutrition Analysis Agent
- Calorie Calculation Agent
- Meal Planning Agent
- Exercise Recommendation Agent
- Progress Monitoring Agent

---

## Technologies

- Python
- Streamlit
- Groq API (Free)
- SQLite
- Plotly

---

## Installation

### Clone Repository

bash
git clone <your_repo_url>


### Install Packages

bash
pip install -r requirements.txt


### Create Environment File

Rename


.env.example


to


.env


Paste your Groq API key.


GROQ_API_KEY=your_key_here


---

## Run

bash
streamlit run app.py
